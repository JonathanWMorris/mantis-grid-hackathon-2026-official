# Saved completed investigation

This is a replay of routed development case 0 from the frozen implementation's 300-second comparison. It completed in 215.96 seconds. It is not a live demo or evidence of hidden-deployment accuracy.

`decision.json` contains the accepted diagnosis and support references. `evidence.md` is the original generated report. `prolog/` contains the exact supporting query, facts, trusted rules, engine, results, and stdout/stderr. The execution ID links the saved decision to the result. Raw model traces and dataset files are not included.

The model's diagnosis is conditional on its assumptions. In particular, a normal `system.mem.total` metric does not establish absence of host memory pressure. The accepted completion gate verifies execution and evidence linkage, not the scientific validity of every inference. Consult the main report for scored correctness.
